# Certificate Documents (`/certs`)

Store your official certificate PDF or image files in this directory.

### Example file names:
- `claude-certified-architect.pdf`
- `100-days-of-cloud.pdf`
- `aws-cloud-foundations.pdf`
- `docker-for-beginners.pdf`
- `infosys-cloud-computing.pdf`

When you add a file here, simply add `data-cert-file="certs/your-file.pdf"` to the corresponding certificate block in `index.html`, and visitors will see a **"Download Certificate 📥"** button inside the interactive Certificate Viewer popup!
